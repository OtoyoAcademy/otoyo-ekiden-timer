# 駅伝大会運営システム v1.0

GitHub Pages + Supabase で動作する、駅伝大会・ファンランの申込、計測、結果、表彰、年度管理をまとめたWebアプリです。

## v1.0 の主な機能

- 駅伝チーム申込、承認、4桁チームアクセスコード
- ファンラン受付、当日受付、参加済み管理
- A/B/C 最大3名の運営計測、2名平均・3名中央値、0.5秒超の差を要確認表示
- チーム参考計測と正式記録への採用
- 区間数1〜30、区間ごとの距離設定
- 速報、正式結果、個人賞の段階公開
- チーム総合・個人最速・男女別・年代別表彰
- A4縦の表彰状、個人記録証、ファンラン「がんばったで賞」
- 証書背景テンプレートのダウンロード／アップロード、画像印／文字角印
- 年度別大会管理、前年設定コピー、過去大会閲覧・削除
- 本番前チェックリスト
- 現在大会JSONバックアップ／復元、各種CSV出力
- PWA対応

## 更新方法

このv1.0は v0.15.1 のSupabase構成をそのまま利用します。**v1.0用の追加SQLはありません。**
GitHub Pagesのリポジトリを本ZIPの内容で上書きしてください。

## 本番前

管理者画面の「本番前チェック」を確認してください。特に管理者・計測係A/B/Cの初期コードは必ず変更し、JSONバックアップを安全な場所へ保存してください。

## バックアップ

「現在大会をJSONバックアップ」には申込情報・計測情報・チーム用アクセスコードが含まれます。個人情報を含むため取り扱いに注意してください。管理者・計測係の秘密コードは含まれません。

## 最終確認

v1.0候補版として通常機能は実装済みです。本番前に複数端末でA/B/C計測、同時通過、通信切断→復旧、チーム参考計測を実機テストしてください。

## 本番前の最終テスト

複数端末を使う計測機能だけは、実機での最終確認が必要です。`V1_TEST_CHECKLIST.md` に確認項目をまとめています。


## v1.0.2 追加・修正
- 個人表彰は同じ走者の最速1本だけを対象にします。
- 全個人表彰を通して1人1回のみ受賞し、重複時は次の別選手を繰り上げます。
- ファンラン申込でメダルの動物を8種類から選択できます。
- ファンランメダルはA4縦・8枚（2列×4段）で印刷できます。
- ファンラン参加証の本文を未就学児向けのひらがな中心に変更しました。
- 表彰状・記録証のA4縦レイアウトを再調整しました。
- ファンラン参加証の背景装飾を枠内に収めました。

Supabaseの追加SQLは不要です。既存の `funRunEntries` JSONに `animal` を追加するだけで、旧データはチーターとして互換表示します。

### v1.0.2 印刷レイアウト修正
証書類はA4縦の実寸mm指定で配置する方式に統一しました。メダルは背景画像に含まれる名前欄を利用し、可変文字のみを重ねる方式です。Supabase追加SQLは不要です。
