# Otoyo Ekiden Timer v0.15

GitHub Pages + Supabase で動く駅伝大会運営アプリです。

## v0.15 の追加
- ファンラン参加受付（締切なし・当日受付可）
- 一般公開フォームと管理者の当日クイック受付
- ファンラン参加者一覧・人数集計・参加済みチェック
- ファンラン参加者CSV出力
- 「がんばったで賞」個別／一括PDF・印刷
- ファンラン参加証テンプレートのダウンロード・編集版アップロード
- ファンラン受付QRコード
- 年度切替時の設定引継ぎ、参加者データのリセット・過去大会保存

## 更新手順
1. `supabase-patch-v0.15.sql` を Supabase SQL Editor で1回実行
2. ZIP内のファイルを GitHub Pages のリポジトリへ上書き
3. 管理者画面でファンラン設定を確認
4. トップ画面のファンラン受付からダミーではないテスト受付を1件行い、管理者一覧へ反映されることを確認

ファンランの個人情報は一般閲覧できず、一般利用者はRPC経由で受付データを書き込むだけです。
